# The Dreamday Events

Official website for The Dreamday Events — event planning and execution in Bengaluru and across Karnataka.

Built with Next.js, Tailwind CSS, and next-themes.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment

This site is deployed to Vercel. Connect your domain in Vercel project settings, then update `robots.txt`, `sitemap.xml`, and JSON-LD with the final domain.
